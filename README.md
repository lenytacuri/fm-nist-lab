## Objetivos de aprendizaje

Entrenar y evaluar redes neuronales para clasificar imágenes de Fashion-MNIST utilizando PyTorch Lightning. El laboratorio aborda:

- Organización de datos y modelos mediante `LightningDataModule`, `DataLoader` y `LightningModule`.
- Entrenamiento en GPU con parada temprana y guardado de los mejores modelos.
- Visualización del entrenamiento con TensorBoard y del grafo computacional con Torchviz.
- Comparación de arquitecturas mediante validación cruzada estratificada de cinco folds y pruebas estadísticas.
- Uso de regularización L2 e implementación de L1 en la función de pérdida.
